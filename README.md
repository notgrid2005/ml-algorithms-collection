Machine Learning algorithms implemented **from scratch** in Python.

## Algorithms
| Algorithm | Type | File |
|-----------|------|------|
| Linear Regression | Regression | `algorithms/linear_regression.py` |
| Logistic Regression | Classification | `algorithms/logistic_regression.py` |
| K-Means | Clustering | `algorithms/kmeans.py` |
| Decision Tree | Classification | `algorithms/decision_tree.py` |
| K-Nearest Neighbors | Classification | `algorithms/knn.py` |
